# Próximos passos

Estas são melhorias práticas para continuar o projeto e criar um histórico de commits compreensível:

- [ ] Adicionar filtro por categoria na lista de chamados.
- [ ] Exibir uma confirmação antes de fechar um chamado.
- [ ] Criar paginação na API (`page`, `size`) e atualizar a interface.
- [ ] Testar a aplicação completa com Docker e registrar resultados.
- [ ] Escrever testes de integração para abertura e alteração de chamados.
- [ ] Adicionar capturas reais da interface em `docs/imagens/`.
- [ ] Configurar uma demonstração hospedada em ambiente seguro, sem dados reais.

Para cada melhoria, faça um commit com uma mensagem específica explicando a alteração.
